Aprendizaje práctico

¿Qué aprenderás?

Durante el curso conocerás las bases necesarias para construir una landing page funcional, ordenada y adaptable a distintos dispositivos.

  • Estructurar páginas con HTML5 semántico.
  • Aplicar estilos con CSS3 para mejorar la presentación visual.
  • Crear interacciones básicas con JavaScript.
  • Manipular elementos del DOM y responder a eventos.
  • Adaptar interfaces a celulares mediante diseño responsivo.
  • Mejorar accesibilidad, usabilidad y optimización básica.

Contenido por semanas

Temario por módulos

01

Módulo 1: estructura, estilos y JavaScript básico

Aprenderás a organizar una página con HTML5, aplicar estilos iniciales con CSS3 y conectar JavaScript al documento. Este módulo establece las bases para crear una página clara y funcional.

02

Módulo 2: interactividad, componentes y diseño responsivo

Construirás secciones reutilizables, trabajarás con eventos y mejorarás la experiencia visual en diferentes tamaños de pantalla. También practicarás el uso de Flexbox y CSS Grid.

03

Módulo 3: optimización, accesibilidad y experiencia de usuario

Revisarás buenas prácticas para que la página sea fácil de usar, legible y eficiente. Además, validarás formularios y mejorarás detalles de navegación, contraste y mensajes para el usuario.
